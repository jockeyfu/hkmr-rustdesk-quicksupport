# HKMR RustDesk QuickSupport

Preconfigured official [RustDesk 1.5.3](https://github.com/rustdesk/rustdesk/releases/tag/1.5.3) Windows x64 client for HKMR remote support.

Download the zip from [Releases](https://github.com/jockeyfu/hkmr-rustdesk-quicksupport/releases), unzip, and run the exe without renaming it. The long filename contains the self-hosted server settings. Tell the support person the ID and one-time password shown on screen.

The exe is the official `rustdesk-1.5.3-x86_64.exe` (SHA-256 `523ba0efbf62a21739961b62c7daaffb44d3da86139c546b364fd4e1333ed249`), only renamed so it points at the HKMR server.
